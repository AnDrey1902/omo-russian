# learn-OMO: разбираемся, как устроен Oh My OpenCode — простыми словами

> Это упрощённый пересказ документации проекта [learn-OMO](https://github.com/yangheng/learn-OMO). Оригинал написан для опытных разработчиков. Здесь та же история, но объяснённая так, чтобы её понял даже школьник — с аналогиями и схемами вместо кусков кода.
>
> Рядом с каждой "человеческой" аналогией везде указан настоящий термин OMO (на английском) — так, начав пользоваться инструментом по-настоящему, ты сразу узнаешь знакомые слова в интерфейсе и документации.

## О чём вообще речь

Представь, что у тебя есть очень способный, но немного бестолковый помощник — обычный ИИ-программист (это называется **OpenCode**). Он умеет писать код, но не умеет сам себя организовывать: не помнит, кого позвать на помощь, что делать при ошибке, как разбить большую задачу на маленькие.

**OMO (Oh My OpenCode)** — это как если бы к этому помощнику приставили целую **команду роботов**: начальника, исполнителей, разведчиков, библиотекаря, мудреца-советчика и строгого критика. Каждый знает свою работу. Вместе они умеют доводить сложные задачи до конца, даже если что-то пошло не так.

Вся документация — это одна большая история: ты говоришь "почини мне вот этот кусок кода", и мы шаг за шагом смотрим, что происходит внутри, от первой миллисекунды до финального "Готово!".

## Словарь: "по-нашему" ↔ "по-настоящему"

Чтобы было легко потом читать настоящую документацию или настройки OMO, вот таблица соответствий терминов из нашего пересказа официальным названиям:

| Наша аналогия | Настоящий термин OMO | Что это такое |
|---|---|---|
| Плагин / надстройка | **Plugin** | Сам OMO — модуль, который подключается к OpenCode |
| Контролёр | **Hook** | Скрытый обработчик, который перехватывает события и вызовы инструментов |
| Инструмент | **Tool** | Конкретное действие, которым может воспользоваться робот (поиск, редактирование и т.д.) |
| Специалист / робот | **Agent** | Отдельная "роль" с собственной инструкцией и правами |
| Сизиф | **Sisyphus** | Главный агент-оркестратор (primary agent) |
| Исполнитель ("младший Сизиф") | **Sisyphus-Junior** | Агент, который реально выполняет переданную работу |
| Следопыт | **Explore** | Агент для поиска по коду внутри проекта |
| Библиотекарь | **Librarian** | Агент для поиска во внешней документации и коде |
| Мудрец | **Oracle** | Агент-консультант только для чтения и анализа |
| Советник | **Metis** | Агент, который проверяет план до его составления |
| Стратег | **Prometheus** | Агент-планировщик, которому запрещено писать код |
| Критик | **Momus** | Агент, который проверяет и отклоняет планы |
| Дирижёр | **Atlas** | Агент-оркестратор для больших задач |
| Передать поручение | **delegate_task** | Инструмент передачи задачи другому агенту |
| Позвать специалиста напрямую | **call_omo_agent** | Инструмент прямого вызова конкретного агента |
| Шпаргалка со знаниями | **Skill** | Файл с профильными знаниями, который подключают к задаче |
| Режим работы | **Category** | Заранее настроенное окружение (модель, температура) для задачи |
| Цикл-Ральф | **Ralph Loop** | Механизм автоповтора, пока задача не завершена |
| Метка завершения | **Completion Promise** (`<promise>DONE</promise>`) | Сигнал агента о том, что задача реально закончена |
| Диспетчер фоновых задач | **BackgroundManager** | Модуль, который запускает и контролирует параллельных агентов |
