# Oh-My-Opencode — простым языком

Русский перевод-пересказ авторского руководства
**[learn-OMO](https://github.com/yangheng/learn-OMO)** (автор — [yangheng](https://github.com/yangheng)).
Оригинал — разбор исходников [Oh My OpenCode](https://github.com/opensoft/oh-my-opencode)
(надстройки над [OpenCode](https://github.com/sst/opencode)) на китайском и английском,
написанный для опытных разработчиков.

Здесь та же история, но простым и понятным языком — так, чтобы разобрался даже школьник:
с аналогиями и схемами вместо кусков кода. Рядом с каждой «человеческой» аналогией указан
настоящий английский термин — чтобы потом было легко читать официальную документацию.

📖 **Читать онлайн:** сайт собирается из этих файлов командой `python build.py`
и публикуется в `site/` (деплой — Vercel).
